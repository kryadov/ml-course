# Учебный календарь: 52 недели · LLM + MLOps

**Старт:** День 1 — 23 июля 2026. Темп 5–7 ч/нед, топик приходит ежедневно в 12:30 (Тбилиси).

**Как читать:** каждая неделя = одна тема (ниже). Внутри недели дни идут по ритму:

- **День 1** — новая тема: чтение/теория + короткий разогрев
- **День 2** — углубление: теория + практика на закрепление
- **День 3** — инструменты/детали: разбор + туториал руками
- **День 4** — направляемая практика: минимум чтения, делаем по гайду
- **День 5** — самостоятельная практика: применяем к своему проекту/домену
- **День 6** — мини-проект / интеграция: собрать неделю воедино
- **День 7** — ревью и лёгкий день: конспект, разбор ошибок, отдых

Ежедневное сообщение подставляет под этот ритм конкретный топик изучения и практическую задачу.

## Фаза 1 — Фундамент: Python для данных + классический ML (недели 1–8)

1. Настройка окружения и Python для данных (uv/venv, git, Jupyter, NumPy)
2. pandas — работа с табличными данными (загрузка, фильтры, groupby, merge)
3. Разведочный анализ и визуализация (matplotlib/seaborn, распределения, корреляции)
4. Scikit-Learn: обучение с учителем (train/test, линейные модели, деревья)
5. Метрики и валидация (кросс-валидация, precision/recall/F1, ROC-AUC, переобучение)
6. Пайплайны и фиче-инжиниринг (Pipeline, препроцессинг, категориальные признаки)
7. Проект-фундамент: классификация транзакций (фрод) — полный цикл
8. GPU-окружение: CUDA, PyTorch на 2×L4, Docker, nvidia-smi; закрепление фазы

## Фаза 2 — Нейросети и трансформеры (недели 9–17)

9. PyTorch: тензоры, autograd, обучающий цикл
10. Датасеты/DataLoader, обучение простой сети (MLP)
11. Основы NLP: токенизация, эмбеддинги, что такое языковая модель
12. Механизм внимания (attention) — теория и руками
13. Архитектура трансформера-декодера (Karpathy «Zero to Hero», ч.1)
14. Сборка nanoGPT: bigram → self-attention → блоки
15. Обучение мини-GPT на своём корпусе (формирование корпуса + токенизация)
16. Эксперименты с мини-GPT: гиперпараметры, сэмплинг, оценка
17. Итог фазы: конспект «как работает трансформер» + доработка мини-LLM

## Фаза 3 — Hugging Face, данные и text2sql (недели 18–26)

18. HF-экосистема: Transformers, загрузка и инференс готовых моделей
19. Datasets и Tokenizers; форматы инструкций и chat template
20. Формирование корпуса: очистка, дедупликация, фильтрация качества
21. PEFT: LoRA/QLoRA — теория и первый запуск на L4
22. Инструменты файнтюна: Unsloth (+ обзор Axolotl); рецепт QLoRA
23. **text2sql Проект №1:** сбор корпуса пар (схема+вопрос→SQL), BIRD/Spider
24. **text2sql:** schema linking / retrieval схемы (важнее файнтюна)
25. **text2sql:** файнтюн SQL-модели (Qwen-Coder) на L4
26. **text2sql:** execution accuracy харнесс, сравнение с базой; model card

## Фаза 4 — Оценка, выравнивание, RAG (недели 27–35)

27. Оценка LLM: бенчмарки, LLM-as-judge, ручной ревью
28. text2sql: execution-based reward, RL для reasoning (Think2SQL / Arctic-R1)
29. **Summary-модель:** постановка, датасет (вопрос+таблица→текст)
30. **Summary-модель:** файнтюн и метрика faithfulness (антигаллюцинация)
31. Сквозной пайплайн text2sql: retrieval → SQL → выполнение → summary
32. DPO/выравнивание: теория, сбор пар предпочтений
33. RAG: эмбеддинги, векторные БД (Qdrant/Chroma), retrieval
34. RAG-ассистент по доменным докам; сравнение файнтюн vs RAG vs гибрид
35. Итог фазы: оценочные отчёты по обеим моделям

## Фаза 5 — MLOps / LLMOps (недели 36–43)

36. Версионирование данных: DVC (данные и датасеты под git)
37. Трекинг экспериментов: MLflow (или W&B) — метрики, параметры, артефакты
38. Реестр моделей: MLflow Model Registry, стадии и версии
39. Инференс: vLLM на L4, пропускная способность, квантизация GPTQ/AWQ
40. API: обёртка модели в FastAPI; Docker Compose (модель + вектор.БД + API)
41. CI/CD: GitHub Actions — линт, тесты, авто-прогон оценки
42. Сборка полного MLOps-контура вокруг text2sql-связки
43. Итог фазы: reproducible-пайплайн + дашборд экспериментов

## Фаза 6 — Мониторинг, релизы, 2-й домен, бонус (недели 44–52)

44. LLMOps-эксплуатация: мониторинг качества/дрифта, логирование, стоимость
45. Релизы моделей: версии, changelog, канареечный деплой, откат
46. Continual learning и катастрофическое забывание — риски обновлений
47. Второй домен (фарма или финтех): сбор корпуса, старт цикла
48. Второй домен: файнтюн + оценка
49. Второй домен: деплой + мониторинг, релиз v2 с откатом
50. Мультимодальный бонус: аудио-эмбеддинги (CLAP), диффузия (Stable Diffusion)
51. Бонус: генерация обложек по аудио — LoRA/DreamBooth, пайплайн audio→image
52. Финал: ретроспектива, портфолио, чек-лист «прошёл весь цикл», план развития
